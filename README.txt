PROJECT DESCRIPTION:
ResumeHub is a simple web-based resume management system
developed using PHP and MySQL.

The system allows users to register, login, create resumes,
view resumes, edit resumes and delete resumes.


TECHNOLOGIES USED:
- PHP
- MySQL
- HTML
- CSS
- WAMP Server
- Notepad / VS Code


MAIN FEATURES:
1. User Registration
2. User Login
3. Password Hashing
4. User Logout
5. Dashboard
6. Create Resume
7. View Resume
8. Edit Resume
9. Delete Resume
10. MySQL Database


DATABASE:
Database Name:
resumehub


HOW TO RUN:

1. Install WAMP Server.

2. Start Apache and MySQL.

3. Copy the ResumeHub folder into:

   C:\wamp\www\24AL450\

4. Open phpMyAdmin.

5. Create the ResumeHub database.

6. Create the required users and resumes tables.

7. Open the browser.

8. Enter:

   http://localhost/24AL450/ResumeHub/


PROJECT OBJECTIVE:
The objective of this project is to provide hands-on
experience in developing a dynamic website using PHP,
MySQL, HTML and CSS.


CONCLUSION:
ResumeHub provides a simple platform for students to
create and manage their professional resumes.
